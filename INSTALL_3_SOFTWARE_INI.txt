📦 Ukuran: ~30 MB

═══════════════════════════════════════════════════════════

📥 Download: https://adoptium.net/temurin/releases/
📦 Ukuran: ~180 MB
⏱️ Waktu: 5 menit

3️⃣  ANDROID STUDIO
═══════════════════════════════════════════════════════════

📥 Download: https://developer.android.com/studio
📦 Ukuran: ~1 GB installer + 3GB SDK
⏱️ Waktu: 30-45 menit

Install:
  1. Download Android Studio
  2. Install, centang SEMUA components
  3. Ikuti Setup Wizard
  4. Pilih "Standard Installation"
  5. Accept semua licenses
  6. Tunggu download SDK selesai (~3GB)

Setup ANDROID_HOME (Windows):
  1. Klik Start → cari "Environment Variables"
  2. Klik "Environment Variables" button
  3. System Variables → New:
     - Name: ANDROID_HOME
     - Value: C:\Users\[USERNAME]\AppData\Local\Android\Sdk
  4. Edit "Path", tambahkan:
     - %ANDROID_HOME%\platform-tools
     - %ANDROID_HOME%\cmdline-tools\latest\bin
  5. OK → OK → RESTART TERMINAL

Setup ANDROID_HOME (Mac/Linux):
  Tambahkan ke ~/.bashrc atau ~/.zshrc:
  
  export ANDROID_HOME=$HOME/Library/Android/sdk
  export PATH=$PATH:$ANDROID_HOME/platform-tools
  
  Lalu: source ~/.bashrc

✅ Test: Buka terminal baru, ketik:
   echo %ANDROID_HOME%     (Windows)
   echo $ANDROID_HOME      (Mac/Linux)
   adb --version

🆘 TROUBLESHOOTING:
═══════════════════════════════════════════════════════════

❌ "node tidak dikenali"
   → Restart terminal atau komputer
   → Install ulang Node.js

❌ "java tidak dikenali"
   → Set JAVA_HOME manual (lihat di atas)
   → Pastikan Java 17

❌ "ANDROID_HOME not set"
   → Set manual (lihat di atas)
   → Restart terminal

❌ Build error "SDK not found"
   → Buka Android Studio
   → Tools → SDK Manager
   → Install Android SDK 34
